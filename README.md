# HimalayanOps Website

A responsive static website for HimalayanOps built with plain HTML, CSS, and JavaScript.

## Files

- `index.html` - page structure and content
- `styles.css` - visual design and responsive layout
- `script.js` - mobile navigation, reveal transitions, and form interaction
- `favicon.svg` - brand icon
- `network-scanner.html` - frontend-only simulated scanner demonstration
- `scanner.css` and `scanner.js` - scoped scanner presentation and interactions
- `data/demo-scans.json` - fictional sample scan records used by the demo

## GitHub Pages Deployment for Demo

The site is ready for GitHub Pages deployment.

## Network Scanner demo

Open `network-scanner.html` through the local server or GitHub Pages. The scanner is a frontend-only demonstration: it reads local sample data and never performs network scans. User-entered targets are validated locally and are not sent to a server or saved in browser history.
